# Historical analysis notebooks

These notebooks preserve earlier analyses and their saved outputs. For the current paper comparison, start with the [main README](../../README.md).

Install the analysis dependencies and local source modules as described in the [reproduction guide](../../docs/REPRODUCING.md). The first setup cell locates the repository when opened from this directory. This new setup cell has no saved execution output; the historical cells' outputs are preserved and were not regenerated during reorganization.

Historical builders and execution scripts are in `src/`. Run them from the repository root. They can overwrite notebooks and saved results, so inspect their output paths before rerunning them.
