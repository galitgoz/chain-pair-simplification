# Research sources referenced by historical notebooks

Historical notebooks originally linked to local PDFs in a `papers/` directory. Those PDFs are not distributed in this repository. The links now point here so readers can distinguish a missing local dependency from an included file.

## Global curve simplification

The notebooks refer to **Global Curve Simplification** and its Algorithm 1. The historical local filename was `papers/global curve simplification.pdf`. Obtain the research paper separately before using helper scripts that extract or inspect that PDF.

## Chain pair simplification

The discrete CPS reference is **On the Chain Pair Simplification Problem** by Fan, Filtser, Katz, Wylie and Zhu. The public manuscript is available at <https://arxiv.org/abs/1409.2457>. The historical local filename was `papers/chain_pair_simplification.pdf`.

## Thesis

The continuous-fidelity construction is documented in Galit Gozoltzani's master's thesis. The historical local filename was `papers/M_Sc__Thesis___Galit_Gozoltzani.pdf`. A public archival URL is not asserted here; the thesis PDF is not bundled.

These documentation links do not remove PDF dependencies from historical preparation scripts. See [reproduction limitations](REPRODUCING.md#solver-execution-current-limitations).
